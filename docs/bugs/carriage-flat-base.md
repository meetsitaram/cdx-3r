# Carriage disc sat on a 0.6 mm boss

**Where:** 10_lift_carriage  
**Status:** fixed

| | |
|---|---|
| What | The root disc stood on a small boss, so the whole disc underside needed support. |
| How found | Slicer preview. |
| Cost | None printed. |
| Root cause | A functional boss was left on the print base face. |
| Fix | Boss became a separate printed spacer; the base is flat; lugs got 45° webs. |
| What catches it now | Not automated. Rule in LESSONS: print bases are flat; bosses become separate spacers. |
